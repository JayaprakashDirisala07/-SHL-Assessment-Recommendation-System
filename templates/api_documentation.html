Introduction

The SHL Assessment Recommendation API allows you to programmatically access our recommendation engine to find the most suitable assessments based on your requirements. The API accepts natural language queries and returns relevant SHL assessments ranked by relevance.

Base URL

All API endpoints are relative to:

{{ request.url_root }}

Authentication

Currently, the API is open for public use without authentication. In a production environment, we would implement API keys or OAuth authentication.

Recommendations Endpoint

POST /api/recommendations

Request Parameters

Parameter Type Required Description
query string Yes Natural language query or job description

Response Format

JSON Response 
{
  "status": "success",
  "query": "Java developers with 40 min time limit",
  "recommendations": [
    {
      "name": "Core Java (Entry Level) (New)",
      "url": "https://www.shl.com/solutions/products/product-catalog/view/core-java-entry-level-new/",
      "remoteTestingSupport": true,
      "adaptiveSupport": true,
      "duration": "35 minutes",
      "testType": "Programming"
    },
    // Additional recommendations...
  ]
}

Evaluation Endpoint

GET /api/evaluation

Request Parameters

Parameter Type Required Default Description
k integer No 3 Number of top results to consider in metrics

Response Format

JSON Response 
{
  "status": "success",
  "metrics": {
    "meanRecallAtK": 0.8533,
    "mapAtK": 0.7925,
    "k": 3
  }
}

Code Examples

JavaScript / Fetch API

Get Recommendations 
fetch('{{ request.url_root }}api/recommendations', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    query: "Java developers with 40 min time limit"
  })
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error('Error:', error));

Python / Requests

Get Recommendations 
import requests
import json

url = "{{ request.url_root }}api/recommendations"
payload = {
    "query": "Java developers with 40 min time limit"
}
headers = {
    "Content-Type": "application/json"
}

response = requests.post(url, data=json.dumps(payload), headers=headers)
print(response.json())

cURL

Get Recommendations 
curl -X POST "{{ request.url_root }}api/recommendations" \
  -H "Content-Type: application/json" \
  -d '{"query": "Java developers with 40 min time limit"}'
